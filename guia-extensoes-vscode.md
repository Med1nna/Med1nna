# 🚀 Guia Definitivo de Extensões Essenciais para VS Code

Uma curadoria completa de extensões voltadas para produtividade, qualidade de código e integração de ferramentas, organizadas por área de desenvolvimento.

---

## 🐍 1. Python (Back-end & Automação)
| Extensão | Descrição Principal |
| :--- | :--- |
| **Python + Pylance** | Infraestrutura base da Microsoft: autocomplete, linting nativo, tipagem estática e depuração (debug) passo a passo. |
| **Ruff** | Linter e formatador ultrarrápido em Rust (substitui Flake8, Black e isort). Corrige código e imports instantaneamente. |
| **autoDocstring** | Gera templates de documentação (*docstrings*) automaticamente para classes e funções mapeando parâmetros e retornos. |

## 🌐 2. Desenvolvimento Web (Front-end)
| Extensão | Descrição Principal |
| :--- | :--- |
| **Live Server** | Inicia um servidor local com *live reload*, atualizando o navegador instantaneamente ao salvar HTML/CSS/JS. |
| **Auto Rename Tag** | Renomeia tags de fechamento automaticamente ao alterar a respectiva tag de abertura (HTML/XML). |
| **ESLint** | Linter padrão da indústria para JS/TS. Encontra inconsistências e evita erros lógicos antes da execução. |
| **CSS Peek** | Permite visualizar e navegar até a regra CSS de uma classe diretamente de dentro do arquivo HTML (`F12`). |
| **Color Highlight** | Renderiza a cor real como plano de fundo de códigos hexadecimais, RGB e HSL no próprio editor. |

## 🔌 3. APIs e Requisições HTTP
| Extensão | Descrição Principal |
| :--- | :--- |
| **Thunder Client** | Cliente REST leve integrado ao editor para testar endpoints e headers (excelente alternativa rápida ao Postman). |
| **REST Client** | Permite disparar requisições HTTP a partir de arquivos texto puros (`.http` ou `.rest`), facilitando o versionamento. |
| **OpenAPI (Swagger) Editor** | Auxilia na escrita, autocompletar e validação de sintaxe de documentações de API no formato Swagger/OpenAPI. |

## 🗄️ 4. Banco de Dados
| Extensão | Descrição Principal |
| :--- | :--- |
| **Database Client** | Conexão unificada para gerenciar PostgreSQL, MySQL, SQLite, SQL Server e Redis diretamente do VS Code. |
| **SQLTools** | Gerenciador de conexões SQL que mantém histórico de queries e permite executar blocos de código específicos. |
| **SQLite Viewer** | Permite abrir, inspecionar e visualizar o conteúdo de arquivos locais `.db` ou `.sqlite` em formato de tabela. |

## 🐙 5. Git e GitHub
| Extensão | Descrição Principal |
| :--- | :--- |
| **GitLens** | Adiciona autoria inline em tempo real (*git blame*), histórico profundo de edições e comparação visual de *branches*. |
| **GitHub Pull Requests and Issues** | Permite criar, revisar e aprovar PRs, além de gerenciar issues diretamente sem abrir o navegador. |
| **Git Graph** | Exibe um grafo visual e interativo de todo o histórico de commits do repositório, facilitando a análise de ramificações. |

## ⚡ 6. Produtividade, Qualidade e Visual
| Extensão | Descrição Principal |
| :--- | :--- |
| **Error Lens** | Exibe mensagens de erro, alertas e warnings diretamente escritos na linha do código, sem precisar passar o mouse. |
| **Prettier - Code Formatter** | Padronizador automático e consistente de formatação (espaçamentos, quebras de linha) para várias linguagens. |
| **Todo Tree** | Mapeia tags de comentários como `TODO`, `FIXME` e `NOTE`, organizando-as em uma árvore de tarefas na barra lateral. |
| **Path Intellisense** | Fornece autocomplete inteligente de nomes de arquivos e pastas na hora de importar módulos ou assets. |
| **Material Icon Theme** | Conjunto visual de ícones limpos para diferenciar rapidamente tipos de arquivos e pastas no explorador do projeto. |
| **Better Comments** | Colore comentários no código usando prefixos (como `!`, `?`, `*`), criando destaques visuais para notas e alertas. |
